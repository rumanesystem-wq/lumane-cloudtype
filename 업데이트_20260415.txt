[ 신규 기능 ]

- 카톡 스타일 UI 전면 개편
  말풍선 분리, 메시지 시간 표시, 길게 눌러 복사

- 메시지 삭제 / 수정
  내 메시지 우클릭 → 수정 또는 삭제

- 답장 (Reply)
  특정 메시지에 인용 답장, 말풍선 위에 인용 블록 표시

- 동영상 / 음성 재생
  mp4, webm, mov, mp3, wav, m4a 첨부 시 플레이어로 바로 재생

- 채팅 내 검색 🔍
  고객·상담원 공통 / ∧∨ 버튼으로 이전·다음 탐색 / 하이라이트 표시

- 파일 첨부 팝업 → 인라인 칩 방식 교체 (고객·상담원 공통)
  전송 전 파일명·썸네일 표시, X 버튼으로 취소

- 썸네일 클릭 → 라이트박스 확대
  첨부 이미지 클릭 시 전체화면으로 크게 보기

- Ctrl+V 클립보드 이미지 붙여넣기
  화면 캡처 후 바로 붙여넣어 전송

- 링크 미리보기 카드
  URL 입력 시 제목·설명·썸네일 자동 표시
  YouTube는 oEmbed API로 영상 제목·채널명·썸네일 표시

- 우클릭 컨텍스트 메뉴 (고객·상담원 공통)
  호버 액션바 → 우클릭 메뉴로 변경 (복사·답장·수정·삭제)
  모바일 롱프레스(600ms) 지원

- 상담원 패널 검색·답장·동영상 재생
  고객 채팅과 동일한 기능을 상담원 라이브 채팅에도 적용

- 새로고침해도 대화 내용 유지
  localStorage에 히스토리 저장 → 새로고침 시 복원

- 이전 상담 이력 Supabase 연동
  전화번호로 이전 상담 기록 실시간 조회

- 상담 자동 저장
  접수 확정 시 자동 저장 (수동 버튼 제거)

- 배포 자동 새로고침
  새 버전 배포 시 30초 내 자동 감지 후 최신 버전 로드
