# 케이트블랑 드레스룸 홈페이지

맞춤 드레스룸 설계·시공 브랜드 **케이트블랑**의 랜딩 페이지 + 블로그 탭 + 견적요청 폼으로 구성된 단일 페이지 애플리케이션(SPA)입니다.

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 케이트블랑 드레스룸 홈페이지 |
| 목적 | 브랜드 소개 + 견적 접수 + 블로그 연결 |
| 기술 스택 | HTML5, CSS3, Vanilla JavaScript |
| 외부 라이브러리 | Font Awesome 6.4 (CDN) |
| 반응형 | 모바일(375px~) / 태블릿 / 데스크톱 |
| 데이터 저장 | RESTful Table API (`tables/quote_requests`) |

---

## 🗂️ 파일 구조

```
/
├── index.html            # 메인 SPA (홈 / 블로그 / 견적요청 탭)
├── css/
│   └── style.css         # 전역 스타일 (변수·레이아웃·컴포넌트·반응형)
├── js/
│   └── main.js           # 페이지 전환, FAQ, 모달, 폼 제출 로직
└── admin/
    └── index.html        # 관리자 페이지 (견적 목록·상태 관리)
```

## ✅ 구현된 기능

### 공통 UI
- [x] 상단 고정 헤더 (로고 + 네비게이션 3개 탭)
- [x] 모바일 햄버거 메뉴
- [x] 우측 하단 플로팅 "견적요청" 버튼 (부유 애니메이션)
- [x] 스크롤 시 헤더 그림자 효과
- [x] 공통 푸터

### [홈] 페이지
- [x] 히어로 섹션 (헤드라인 + CTA 버튼 2개 + 드레스룸 비주얼 카드)
- [x] 브랜드 소개 + 통계 (시공 완료, 고객 만족도, A/S 기간)
- [x] 핵심 장점 4가지 카드 (아이콘 + 설명)
- [x] 구성 옵션 8가지 카드 (아일랜드장, 거울장, 화장대 등)
- [x] 시공 과정 Step 1~4
- [x] 시공 후기 블로그 링크 섹션 (갤러리 대체 → 네이버 블로그 바로가기 + 미리보기 이미지 3장)
- [x] FAQ 아코디언 6개
- [x] 하단 CTA 섹션

### [블로그] 페이지
- [x] 네이버 블로그 바로가기 버튼 (https://blog.naver.com/kateblanc_)
- [x] 더미 블로그 카드 6개 (카테고리 배지: 시공후기/정보/팁)
- [x] 하단 CTA → 견적요청 페이지 이동

### [견적요청] 페이지
- [x] 필수 항목: 이름, 연락처, 설치 지역, 가로/세로/높이(mm), 형태(라디오)
- [x] 선택 항목: 옵션 체크박스(8개), 프레임 색상, 선반 색상(기타 직접 입력), 파일 첨부, 요청사항
- [x] 개인정보 동의 (상세 내용 토글)
- [x] 실시간 폼 유효성 검사 (필드별 에러 메시지)
- [x] 연락처 자동 포맷팅 (010-0000-0000)
- [x] 제출 후 완료 화면 표시
- [x] **RESTful Table API로 DB 저장** (`tables/quote_requests`)
- [x] **견적 제출 시 웹훅 호출** (`QUOTE_WEBHOOK_URL` 변수 설정 시 자동 발송)

### [관리자] 페이지 (`/admin/`)
- [x] 비밀번호 인증 (기본값: `kateblanc2025!`)
- [x] 접수 통계 (전체/접수/검토중/완료)
- [x] 견적 목록 테이블 (이름, 연락처, 지역, 형태, 사이즈, 옵션, 상태)
- [x] 검색 필터 (이름·연락처·지역)
- [x] 상태 필터 (접수/검토중/완료)
- [x] 상세 모달 (모든 필드 + 상태 변경 드롭다운)
- [x] 처리 상태 변경 (PATCH API)
- [x] 견적 삭제 (DELETE API)
- [x] 페이지네이션 (15건/페이지)

## 🔗 접근 경로

| 경로 | 설명 |
|------|------|
| `/` 또는 `/index.html` | 홈 (상세 페이지 랜딩) |
| `/#blog` → 블로그 탭 | 탭 전환 (JS 내 `showPage('blog')`) |
| `/#quote` → 견적요청 탭 | 탭 전환 (JS 내 `showPage('quote')`) |
| `/admin/` | 관리자 페이지 |

## 🗄️ 데이터 모델

### `quote_requests` 테이블

| 필드명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| `id` | text | auto | 고유 ID (UUID) |
| `name` | text | ✅ | 이름 |
| `phone` | text | ✅ | 연락처 |
| `region` | text | ✅ | 설치 지역 |
| `width` | number | ✅ | 가로 (mm) |
| `depth` | number | ✅ | 세로 (mm) |
| `height` | number | ✅ | 높이 (mm) |
| `layout_type` | text | ✅ | 형태 (1자/ㄱ자/ㄷ자/11자/잘 모르겠어요) |
| `options` | array | — | 선택 옵션 목록 |
| `frame_color` | text | — | 프레임 색상 |
| `shelf_color` | text | — | 선반 색상 |
| `request_memo` | rich_text | — | 요청사항 |
| `privacy_agreed` | bool | ✅ | 개인정보 동의 여부 |
| `status` | text | — | 처리 상태 (접수/검토중/완료) |
| `created_at` | datetime | auto | 접수 일시 |

## ⚙️ 관리자 비밀번호 변경 방법

`admin/index.html` 상단 스크립트에서 다음 줄을 수정하세요:

```js
const ADMIN_PASSWORD = 'kateblanc2025!';  // 여기를 변경
```

> ⚠️ 현재 비밀번호는 클라이언트 코드에 포함되어 있습니다. 실 운영 환경에서는 서버 사이드 인증으로 전환하는 것을 권장합니다.
